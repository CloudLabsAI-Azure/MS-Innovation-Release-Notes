## Release Date: 2026-11-23

### Summary of Changes

Onboarded a new lab, **Build a Real-Time Data Foundation for BI and AI Agents**, built on Microsoft Fabric. The lab shows how one governed data platform serves both business reporting and AI, using a Contoso Retail campaign scenario that brings trusted customer data and live website activity together to support a business decision. Developed the lab guide, the automated lab environment, the screenshots, and the solution architecture diagram.

### Infrastructure Changes

- Configured the lab deployment template to provision an **F2 Fabric Capacity** for each learner.
- Configured the lab virtual machine with the **Standard_D2s_v5** size.
- Automated the creation of the Fabric workspace, the sales lakehouse with customer and product data, the live website activity stream, and the Fabric data agent.
- Added simulated website activity that starts automatically with the lab environment.

### Content Changes

- Created the **Getting Started** page with the business scenario, lab objectives, prerequisites, solution architecture, and lab access steps.
- **Exercise 1: Governed Lakehouse, Ingest with Lineage and Permissions:** Covers the governed lakehouse with trusted customer and product data, data lineage, and a data-quality check.
- **Exercise 2: Real-Time with an Operational Action:** Covers live website activity, a real-time campaign dashboard, and an automatic email alert on the campaign target.
- **Exercise 3: Decide with Power BI and Feed the Agent:** Covers a Power BI decision report and a Fabric data agent that answers business questions in plain language.
- Aligned all lab instructions with the latest Microsoft Fabric experience.

### Screenshot Updates

- Added new screenshots for Getting Started and all exercises to reflect the latest Microsoft Fabric interface.
- Added a new solution architecture diagram for the lab.
