## Release Date: 2026-10-16
 
### Summary of Changes

This release improves the Nerdio Manager for MSP workshop to give learners a more reliable, secure, and up-to-date experience. The lab guides were refreshed to match the latest Nerdio Manager for MSP and Azure portal experience.

### Infrastructure Changes

- Improved environment reliability with an automated readiness check, which confirms that all core services are deployed and configured successfully.
- Improved security: learners now see only the credentials they need to perform the lab.
- Automated user creation steps, so partcipants do not need to perform it manually now. 

### Content Changes

- Refreshed the Getting Started page with a clear scenario, overview, objectives for each lab, prerequisites, and an architecture overview.
- Aligned the scenario, overview, objectives, and summary of each lab with the updated exercises.
- Simplified user setup in Lab 2, with clear guidance on which sign-in credentials to use in each later step.
- Enhanced Lab 5 to cover **FSLogix App Masking**, which shows how to control which users can see Microsoft 365 Apps, and in Lab 5 Task 5 updated the instructions with an explanation of monitoring insights, with a walkthrough of each insights view.
- Updated Lab 6 to follow the latest **MSP Cost Estimator** experience, with focused inputs that match the environment built during the workshop.
- Reviewed and refined punctuation, grammar, and sentence structure throughout the lab content, so it reads consistently and learners have a clear and seamless experience.

### Screenshot Updates

- Added a new architecture diagram that gives a clear, high-level view of the workshop's components.
- Updated screenshots across all labs to match the latest Nerdio Manager for MSP and Azure portal interfaces, so learners have clear and up-to-date guidance.

### Testing Notes

- **Testing Date**: 2026-10-16

### Testing Scope 

Conducted end-to-end testing, confirmed that all lab tasks can be completed as written, that content is accurate, consistent, and clear, and that it aligns with the workshop flow for a seamless learner experience.
